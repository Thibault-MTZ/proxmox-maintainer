# Direction avancée

Cette branche reprend le moteur de la bêta minimale. La découverte A/Entrée est plus riche : paquets reconnus, services actifs, écoutes, fichiers de dépôts et conteneurs Docker actifs. Le programme ne lit pas les environnements Docker ou les fichiers de secrets.

Pas encore implémentés : édition du catalogue depuis le TUI, dépendances entre services, contrôles UX applicatifs, mise à jour d’images Docker/Compose, changement de canal, gestion de snapshots, reprise transactionnelle et notifications.

Cette branche sert à expérimenter et recueillir des avis. Le portage n’est pas une validation de production. Toute action réelle reste soumise aux mêmes confirmations, sauvegardes et limites que la version minimale.
